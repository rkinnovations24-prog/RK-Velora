# RK VELORA KITCHEN & BATH CO. - UNIVERSAL WEBSITE PRD

Create a premium luxury corporate website for Velora Kitchen & Bath Co. inspired by brands like Kohler, Grohe, Hansgrohe, Jaquar and TOTO. The website should feel modern, elegant, spacious and premium with a black, white and gold color palette. Use high-quality realistic lifestyle photography, premium typography, clean layouts, large whitespace, subtle animations and refined UI components. The website should focus on enquiry generation and brand trust instead of eCommerce. This is a fully custom-coded static website with no CMS or admin dashboard.
